데일리 초성

개인정보 처리방침

시행일: 2026년 11월 5일

데일리 초성 운영자(이하 운영자)는 「개인정보 보호법」 제30조에 따라 iPhone 앱 데일리 초성의 개인정보 처리 내용을 공개합니다.

회원가입 없이 플레이할 수 있어요. 설정에서 점수와 오류 보내기를 끄거나, 게임 기록과 서버에 보낸 점수 및 단어를 지울 수 있어요. 서버는 일본, 오류 진단 서비스는 미국에 있어요.

1. 처리 목적과 항목

점수와 일별 평균
앱이 만든 무작위 설치 ID, 퍼즐 날짜, 점수, 서버 저장 시각을 처리합니다. 설정의 점수와 오류 보내기가 켜져 있을 때 그날의 점수를 보내며, 같은 설치의 중복 점수를 구분하고 일별 평균을 계산하는 데 씁니다.
단어 검토 요청
이용자가 직접 고른 단어, 설치 ID, 퍼즐 날짜, 검토 상태, 서버 저장 시각을 처리합니다. 단어 목록을 개선하고 검토 이력을 관리하는 데 씁니다. 직접 검토를 요청한 단어만 보내며, 점수 전송 설정과는 별개입니다.
앱 오류 진단
오류·비정상 종료·앱 멈춤 정보, 기기 모델과 운영체제·앱 버전, 발생 시각, 앱 실행·종료와 화면 이동·버튼 누름 기록, 실패한 요청 주소 등 오류 분석에 필요한 진단 정보를 Sentry로 보냅니다. Sentry가 별도로 만드는 설치 식별자가 포함됩니다. 요청 주소에 게임의 설치 ID가 포함될 수 있습니다. 앱 오류 진단은 점수와 오류 보내기가 켜져 있을 때만 작동합니다.
서버 오류 진단
오류 내용과 발생 위치·시각, 요청 주소와 방식 등 서버 운영에 필요한 오류 정보를 Sentry로 보냅니다. 설치 데이터 삭제 요청 주소에 설치 ID가 포함될 수 있습니다.
데이터 삭제
설치 ID로 서버에 보관된 점수와 단어 검토 요청을 찾아 삭제합니다.
이메일 문의
이메일 주소, 문의 내용과 이용자가 직접 적은 정보를 문의 응대와 권리 행사 요청 처리에 씁니다.

게임의 설치 ID와 Sentry 식별자는 이름이나 연락처를 묻지 않고 만드는 임의 번호입니다. 같은 설치의 기록을 연결할 수 있으므로 익명 정보로 설명하지 않습니다. 운영자는 이 번호를 이름·연락처를 알아내는 데 사용하지 않습니다.

기기의 위치 권한을 요청하지 않으며, 오류 진단 정보에 포함되는 IP 주소와 위치 정보는 저장하지 않도록 설정하고 있습니다. 광고 식별자(IDFA), 연락처, 사진에는 접근하지 않습니다. 서버 통신 중 IP 주소는 네트워크 처리와 일시적인 요청 제한에 사용되지만, 게임 데이터베이스와 웹 접속 로그에 저장하지 않습니다.

2. 기기에만 저장하는 정보

날짜별 게임 기록, 입력한 단어와 앱 설정은 iPhone에 저장합니다. 운영자가 전체 게임 기록을 읽거나 iCloud로 동기화하는 기능은 없습니다. 1항의 점수·검토 요청·오류 진단 정보만 해당 조건에 따라 전송합니다. 알림은 기기의 알림 기능으로 예약합니다.

3. 처리의 법적 근거와 아동

게임 제공, 이용자가 요청한 단어 검토·문의·데이터 삭제는 「개인정보 보호법」 제15조제1항제4호, 오류 분석과 안정적인 서비스 운영은 같은 항 제6호를 근거로 필요한 범위에서 처리합니다. 점수와 앱 오류 진단은 설정에서 끌 수 있습니다.

만 14세 미만 아동의 이름·연락처를 앱에서 묻지 않으며, 동의를 근거로 아동의 개인정보를 수집하는 기능은 없습니다. 만 14세 미만 이용자가 이메일로 문의할 때는 보호자와 함께 보내 주세요.

4. 보유 기간과 파기

점수와 단어 검토 요청
일별 평균 제공과 검토 이력 관리를 위해 서버에 보관하며, 이용자의 삭제 요청이 처리되거나 서비스가 종료될 때 삭제합니다. 현재 일정 기간이 지나면 자동으로 삭제하는 기능은 없습니다. 더 이상 처리 목적에 필요하지 않은 정보는 삭제합니다.
서버 데이터베이스 백업
백업한 날부터 최대 14일 동안 보관합니다. 운영 데이터에서 삭제한 정보도 기존 백업에 남을 수 있으며, 해당 백업이 만료되면 함께 삭제됩니다. 백업은 장애 복구 목적으로만 사용합니다.
Sentry 오류 이벤트
현재 Developer 플랜의 오류 이벤트 보관 기간은 수집 후 30일입니다. 이용 중인 플랜과 보관 기준이 달라지면 이 방침을 갱신합니다. Sentry가 서비스 보안·운영을 위해 별도로 관리하는 기록에는 해당 제공자의 보관 기준이 적용됩니다.
이메일 문의
문의 처리를 마친 날부터 1년 이내에 삭제합니다. 권리 행사 요청의 처리가 끝나기 전에는 그 처리에 필요한 정보만 보관합니다.

보유 기간이 끝나거나 처리 목적을 달성하면 해당 전자 기록을 삭제합니다. 법령에 따른 별도 보존 의무가 생기는 경우에는 해당 항목·근거·기간을 안내하고 분리하여 보관합니다.

5. 처리 위탁과 국외 이전

운영자는 아래 서비스에 데이터 보관과 처리를 맡깁니다. 서비스 제공에 필요한 국외 보관·처리위탁은 「개인정보 보호법」 제28조의8제1항제3호에 따라 이 방침에 공개합니다. 판매나 광고 목적의 제3자 제공은 하지 않습니다.

Oracle Cloud · 일본

  • 이전받는 자: Oracle Corporation 및 클라우드 서비스 제공 계열사. 법인별 연락처: Oracle 공식 법인·지역별 안내. 개인정보 문의: privacy_kr_grp@oracle.com
  • 국가: 일본, 오사카 리전
  • 항목: 설치 ID, 퍼즐 날짜, 점수, 검토 요청 단어·상태, 서버 저장 시각과 삭제 요청
  • 시기·방법: 앱 실행·복귀, 게임 완료, 검토·삭제 요청 시 HTTPS로 전송
  • 목적·기간: 게임 서버 운영과 보관. 4항의 점수·검토 요청·백업 기준 적용
  • 제공자 안내: Oracle 서비스 개인정보 처리방침

Sentry · 미국

  • 이전받는 자: Functional Software, Inc. (Sentry). 연락처: compliance@sentry.io
  • 국가: 미국
  • 항목: 1항에 적은 오류 진단 정보 및 식별자
  • 시기·방법: 오류·앱 멈춤 발생, 실행·종료 등 진단 정보 전송 시 HTTPS로 전송
  • 목적·기간: 오류 원인 분석과 해결. 현재 오류 이벤트는 30일
  • 제공자 안내: Sentry 개인정보 처리방침

Google Gmail · 국외 데이터센터

  • 이전받는 자: Google LLC. 연락처: googlekrsupport@google.com
  • 국가: Google이 공개한 운영 시설 소재국은 미국, 대만, 일본, 싱가포르, 아일랜드, 네덜란드, 덴마크, 핀란드, 독일, 벨기에, 영국, 우루과이, 칠레입니다. Google 데이터센터 위치에서 최신 목록을 확인할 수 있습니다. Gmail의 개별 메시지가 실제로 저장되는 국가는 운영자가 지정하거나 확인할 수 없습니다.
  • 항목: 이메일 주소, 문의 내용, 이용자가 직접 적은 정보
  • 시기·방법: 이용자가 이메일을 보낼 때 Gmail을 통해 전송·보관
  • 목적·기간: 문의 응대. 처리 완료 후 1년 이내 삭제
  • 제공자 안내: Google 개인정보처리방침

점수와 앱 오류의 국외 이전을 원하지 않으면 설정에서 점수와 오류 보내기를 꺼 주세요. 게임은 계속할 수 있습니다. 검토 요청이나 이메일 문의를 보내지 않으면 해당 정보는 이전되지 않지만, 해당 응대는 받을 수 없습니다. 서버 요청 과정에서 발생하는 서버 오류 진단은 서버 운영을 위해 처리하며 앱에서 개별적으로 끌 수 없습니다.

6. GitHub Pages와 자동 처리

앱은 서버 주소를 확인하려고 GitHub Pages의 설정 파일을 읽습니다. 이 사이트의 안내 페이지와 사전 자료도 GitHub Pages에 있습니다. GitHub는 보안을 위해 방문자의 IP 주소 등을 처리·기록할 수 있으며, 운영자는 개별 방문자의 접속 기록을 제공받지 않습니다. 자세한 내용은 GitHub 개인정보 처리방침에서 확인할 수 있습니다. 이 사이트에는 운영자가 추가한 광고·분석 스크립트나 쿠키가 없습니다.

7. 열람·정정·삭제·처리정지

이용자와 법정대리인은 언제든 아래 이메일로 개인정보 관련 권리를 행사할 수 있습니다. 서버 기록을 확인하려면 앱 설정의 기기 ID 복사 값을 보내 주세요. 불필요한 신분증이나 민감한 정보는 보내지 마세요. 요청을 확인하고 법령이 정한 기간 안에 처리하거나 처리할 수 없는 이유를 안내합니다.

앱에서 게임 기록과 서버 데이터 지우기

  1. 설정 → 개인정보 → 내 데이터 삭제 → 모두 삭제를 선택합니다.
  2. 기기의 게임 기록을 초기화하고 새 설치 ID를 만듭니다. 테마·알림 같은 앱 설정은 유지합니다.
  3. 이전 설치 ID의 점수와 단어 검토 요청을 서버에서 삭제합니다. 인터넷 연결이나 일시적인 요청 제한으로 실패하면 다음 앱 실행·복귀 때 다시 시도합니다.

삭제 요청은 점수 전송을 꺼도 처리합니다. 앱 삭제만으로 서버 데이터가 지워지지는 않습니다. 앱을 삭제하여 이전 설치 ID를 모르면 운영자도 어느 기록이 이용자의 것인지 특정하지 못할 수 있습니다.

앱의 삭제 기능은 게임 서버의 점수·검토 요청을 대상으로 합니다. Sentry 오류 이벤트와 백업은 별도의 보관 기간을 따릅니다. 오류 진단 정보에 관한 권리 행사는 아래 이메일로 문의해 주세요.

8. 안전성 확보 조치

앱·서버 통신에 HTTPS를 사용하고 데이터베이스 접근을 제한합니다. 관리자 페이지는 비밀번호로 보호하며, 서버 접속 권한과 백업을 제한하여 관리합니다. 오류 진단의 IP·위치 정보 저장을 제한하고 광고 추적은 사용하지 않습니다.
